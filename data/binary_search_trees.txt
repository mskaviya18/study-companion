Binary Search Trees

A binary search tree (BST) is a binary tree data structure where each node has at most two children, referred to as the left child and the right child. For every node, all values in its left subtree are smaller than the node's value, and all values in its right subtree are larger.

Insertion in a BST starts at the root and compares the new value with the current node. If the new value is smaller, the algorithm moves to the left child; if larger, it moves to the right child. This continues until an empty spot is found, where the new node is attached.

Searching works the same way as insertion: compare the target value with the current node, move left or right depending on whether the target is smaller or larger, and repeat until the value is found or a null pointer is reached.

The time complexity of search, insertion, and deletion in a balanced BST is O(log n), because each comparison eliminates roughly half of the remaining nodes. However, if the tree becomes unbalanced (for example, if values are inserted in sorted order), the tree degenerates into a structure resembling a linked list, and operations slow down to O(n).

Deletion in a BST has three cases: deleting a leaf node (simply remove it), deleting a node with one child (replace the node with its child), and deleting a node with two children (replace the node's value with its in-order successor, then delete that successor from the right subtree).

Common applications of BSTs include implementing dynamic sets, priority queues, and as the underlying structure for self-balancing trees like AVL trees and Red-Black trees, which add rotation operations to keep the tree height balanced and guarantee O(log n) operations even in the worst case.
